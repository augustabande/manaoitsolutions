# Augusta Bande – Personal Portfolio (React)

⚠️ **Notice:** This project is no longer actively maintained.  
It was originally developed as a **personal portfolio template** using **React 18** and **Create React App** with supporting libraries.  
I keep it online as a **reference project**, but for new work I use **modern stacks** (React 19, Vite, Next.js, Bootstrap 5+, etc.).

---

## ✨ Features
- Personal portfolio single-page application  
- Built with **React 18** and **Create React App**  
- Responsive UI with **Bootstrap 5** and **React-Bootstrap**  
- Dynamic typewriter effect and parallax sections  
- Portfolio grid with **Isotope Layout**  
- Sliders and carousels via **React Slick** + **Slick Carousel**  
- Modal video integration with **React Modal Video**  
- Toast notifications with **React Toastify**  
- Smooth scrolling with **react-scroll**  
- Animations powered by **WOW.js** and **Sass** styling  
- Contact form integration with **EmailJS**
